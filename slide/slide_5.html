Project B: Outdoor Autonomous Robot

Project overview and real-world deployment context

Project Overview

Outdoor autonomous platform for real-route operation

  • Autonomous outdoor robot for waypoint-based navigation
  • Navigation stack built on ROS2 and Navigation2
  • Ackermann steering with tailored odometry and control
  • Designed for stable route following in real outdoor conditions

Technical Challenge

Key problems addressed in the project

  • GPS/RTK integration for stable localization outdoors
  • Reverse-motion planning for constrained maneuvers
  • CAN motor interface with simulation-first validation
  • Reliable behavior across route changes and recovery cases
